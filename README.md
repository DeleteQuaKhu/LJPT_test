# LJPT_test

A sandbox project for testing code and pushing it to GitHub.

## Structure

```
LJPT_test/
└── N2/
    └── test.py
```

## Usage

```bash
cd N2
python test.py
python test.py --name Alice
python test.py --test
```

## Running the tests

```bash
cd N2
python test.py --test
# or
pytest test.py
```

## Requirements

- Python 3.6+
